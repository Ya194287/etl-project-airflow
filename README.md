# ETL-проект: Репликация данных из MongoDB в PostgreSQL с помощью Apache Airflow

## Описание проекта
Данный проект реализует полноценный ETL-процесс для переноса данных из нереляционной базы данных MongoDB в реляционную PostgreSQL с последующим построением аналитических витрин. Оркестрация процесса выполняется с помощью Apache Airflow.

## Стек технологий
*   **Базы данных:** MongoDB (источник), PostgreSQL (хранилище)
*   **Оркестрация:** Apache Airflow 2.11.0
*   **Контейнеризация:** Docker, Docker Compose
*   **Язык:** Python (библиотеки: `pymongo`, `psycopg2`, `apache-airflow-providers-mongo`)

## Архитектура и этапы ETL
1.  **Source (MongoDB):** Генерация и хранение сырых данных о сессиях, событиях, тикетах поддержки и т.д.
2.  **Extract (Airflow):** Извлечение данных из 5 коллекций MongoDB.
3.  **Transform (Airflow):**
    *   Приведение `ObjectId` к строковому типу.
    *   Преобразование вложенных структур (`list`, `dict`) в формат, совместимый с PostgreSQL (`JSONB` или текст).
    *   Обработка массивов строк для корректной вставки.
4.  **Load (Airflow):** Загрузка трансформированных данных в соответствующие таблицы PostgreSQL.
5.  **Data Marts (Airflow):** Создание двух аналитических витрин на основе загруженных данных.
